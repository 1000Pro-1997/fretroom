# fretroom

Guitar Pro 악보를 열어 기타 연습하는 Windows·macOS 데스크톱 앱입니다.

## 다운로드

**[⬇ fretroom.exe 다운로드 (Windows)](https://github.com/1000Pro-1997/fretroom/releases/latest/download/fretroom.exe)** · **[⬇ macOS용 DMG 선택 (Apple Silicon / Intel)](https://github.com/1000Pro-1997/fretroom/releases/latest)** · [모든 릴리스](https://github.com/1000Pro-1997/fretroom/releases)

설치 없이 받은 EXE를 더블클릭하면 실행됩니다. 다른 폴더로 EXE 파일 하나만 복사해도 실행할 수 있습니다. 서명되지 않은 앱이라 처음 실행할 때 Windows SmartScreen이 막으면 **추가 정보 → 실행**을 누르세요.

Windows 휴대용 앱은 켤 때 GitHub의 새 정식 릴리스를 확인합니다. 새 버전이 있으면 백그라운드에서 EXE를 받아 파일 크기와 SHA-256을 확인하고, **지금 다시 시작 / 나중에** 중 고를 수 있습니다. 나중에를 고르면 앱을 닫을 때 교체되고 다음 실행부터 적용됩니다. 인터넷이 끊긴 동안에는 기존 버전으로 계속 사용할 수 있습니다. EXE가 있는 폴더에 쓰기 권한이 있어야 자동으로 교체할 수 있습니다.

### 터미널 한 줄 설치

**Windows** (PowerShell): 바탕화면에 받은 뒤 바로 실행합니다.

```powershell
$ProgressPreference='SilentlyContinue'; $f="$([Environment]::GetFolderPath('Desktop'))\fretroom.exe"; iwr https://github.com/1000Pro-1997/fretroom/releases/latest/download/fretroom.exe -OutFile $f; & $f
```

**macOS** (터미널): Apple Silicon·Intel에 맞는 DMG를 다운로드 폴더에 받고 엽니다.

```sh
arch=$(uname -m); [ "$arch" = x86_64 ] && arch=x64; curl -fL "https://github.com/1000Pro-1997/fretroom/releases/download/v1.0.1/fretroom-1.0.1-mac-$arch.dmg" -o "$HOME/Downloads/fretroom.dmg" && open "$HOME/Downloads/fretroom.dmg"
```

DMG를 열어 앱을 응용 프로그램 폴더로 옮기세요. macOS 앱은 서명·공증되지 않아 첫 실행에 **설정 → 개인정보 보호 및 보안 → 그래도 열기**가 필요할 수 있습니다. 악보 보기·재생·기타 타브 편곡·튜너, 유튜브 소리 인식, PDF·이미지 타브 변환(Audiveris 자동 설치)은 Mac에서도 사용합니다. Mac에서는 새 버전을 알려 주고 DMG 다운로드 링크를 열지만, 앱 자동 교체는 Windows 휴대용 EXE만 지원합니다.

## 바로 실행

이 저장소를 받아 빌드했다면 `release\fretroom.exe`를 더블클릭하세요. 실행 중 서버나 터미널 창이 필요하지 않습니다. `바로열기.bat`도 같은 EXE를 실행하며, EXE가 없다면 Node.js로 첫 빌드를 시도합니다.

Mac에서는 `바로열기.command`를 더블클릭하세요. `release/mac-arm64/fretroom.app`(Intel은 `release/mac/fretroom.app`)을 열고, 앱이 없으면 Node.js로 첫 빌드를 시도합니다.

왼쪽 **악보** 탭은 악보를 폴더별로 묶어 보여 줍니다. 선택한 폴더와 **파일 열기**로 연 악보의 폴더가 각각 폴더 이름으로 표시되고, 이름을 누르면 접거나 펼칩니다(접힌 상태는 저장되며, 검색 중에는 모두 펼쳐 보입니다). 홈 화면에는 **최근 재생한 악보**가 최대 10개 표시됩니다. 악보를 열기만 하면 등록되지 않고, 재생을 시작해야 목록에 올라갑니다. 음표 아이콘을 누르면 그 악보를 열고 **튜너**로 전환합니다. 악보를 **우클릭**하면 즐겨찾기·파일 이름 바꾸기·목록에서 제거 메뉴가 나타나고, 타브로 변환한 PDF·이미지에는 **타브 변환 삭제**도 나타납니다. 즐겨찾기는 목록 맨 위에 모이고, 제거는 원본 파일을 삭제하지 않고 목록에서만 숨깁니다. 홈 화면의 **즐겨찾기 · 목록 관리**에서 즐겨찾기를 해제하거나 숨긴 악보를 복구할 수 있습니다. 파일을 창에 드래그해 열 수도 있습니다.

**파일 연결**: 설치 과정 없이 GP·GP3·GP4·GP5·GPX·GP7·GP8·MusicXML(`.musicxml`, `.mxl`) 파일을 더블클릭하면 fretroom으로 열립니다. 앱이 이미 켜져 있으면 그 창에서 엽니다. macOS는 앱을 응용 프로그램 폴더에 두고 한 번 실행하면 연결됩니다. Windows 휴대용 EXE는 실행할 때마다 현재 사용자 계정(HKCU, 관리자 권한 불필요)에 파일 형식을 등록하고, EXE를 다른 폴더로 옮기면 다음 실행 때 새 위치로 바꿉니다. 다른 앱을 **항상 이 앱으로 열기**로 직접 고른 형식은 그대로 두므로, 그때는 파일 우클릭 → **연결 프로그램**에서 fretroom을 고르세요. EXE를 지운 뒤 남은 연결은 연결 프로그램을 다시 고르면 바뀝니다.

악보 자체를 크게 보여주고, 위쪽에는 **연주 설정**·정지·재생·구간 반복·기타 타브 버튼을 둡니다. **연주 설정**을 누르면 팝업에서 카포(자동 또는 0~7프렛, 고르면 그 카포 위치에 맞춰 기타 타브를 다시 편곡), 재생 속도, 박자(메트로놈), **도돌이표 풀어보기**를 바꿀 수 있고, **초기화**로 자동 카포·100%·박자 끔·도돌이표 풀어보기 켬으로 되돌립니다. 도돌이표 풀어보기는 기본으로 켜지며 실제 연주 순서대로 반복 마디와 다른 결말을 화면에 이어 붙입니다. 재생 커서도 펼친 악보를 따라 앞으로 진행합니다. 끄면 원본의 도돌이표와 재생 순서로 돌아갑니다. 악보의 음표를 클릭하면 해당 위치로 이동합니다. **Space**는 마지막으로 누른 버튼과 상관없이 항상 재생/일시정지만 합니다(글자 입력 칸에서는 제외). 악보를 드래그해 구간을 선택하면 바로 재생하며, 끝과 처음에서 각각 0.5초 멈춘 뒤 구간 반복합니다. 기본 배치는 한 줄 4마디·동일 마디 폭이며 마디 안 음표 간격은 박자 길이에 비례합니다. 여러 파트가 있으면 모두 표시합니다. **연습 설정** 탭에서 파트·배율·마디 수·인코딩을 바꿀 수 있습니다. 설정과 메모·수정한 악보 제목은 컴퓨터에 저장됩니다. 수정본 저장은 원본 GP5를 덮어쓰지 않고 Guitar Pro 7 이상 형식인 `.gp` 파일로 내보냅니다.

**튜너** 탭은 악보에 기록된 기타 줄의 음높이를 목표로 마이크 입력을 분석합니다. 악보를 열지 않았으면 표준 기타 튜닝(E4·B3·G3·D3·A2·E2)을 사용합니다. 튜너 탭을 열면 마이크가 자동으로 켜지고 다른 탭으로 나가면 꺼집니다. 마이크 버튼으로 직접 끄거나 다시 켤 수도 있습니다. 기본 입력은 시스템 기본 마이크이며, **마이크** 목록에서 다른 장치를 선택할 수 있습니다. 선택한 장치는 저장되고, 연결이 끊기면 기본 마이크로 돌아갑니다. 현재 감지된 줄이 ±5센트 이내면 초록색, 벗어나면 빨간색, 소리가 감지되지 않으면 기본 색상입니다. 마이크 권한을 허용해야 사용할 수 있습니다. 재생은 악보의 음 길이·주법을 반영하고, X로 표시된 데드 노트는 Guitar Pro처럼 그 줄의 음을 뮤트 기타 음색으로 짧게 "칙" 끊어 냅니다. 포함된 FluidR3 GM SoundFont로 소리를 내며 자연스러운 현악기 감쇠는 유지됩니다. 오래된 GP5의 한글 파트명이 깨지면 **연습 설정 → 문자 인코딩 → 한국어 (CP949)**를 선택하세요.

## 기타 타브 편곡

위쪽 **기타 타브** 버튼을 켜면 피아노 악보처럼 기타용이 아닌 악보를 표준 튜닝 기타 한 대의 타브·오선보·코드로 바꿔 보여 줍니다. 기타 타브가 없는 악보를 열면 자동으로 켜지며, 켜고 끈 상태는 악보마다 저장됩니다.

- 가장 높은 성부를 멜로디로 정하고, 멜로디는 절대 빼지 않습니다. 가장 낮은 성부는 베이스, 나머지 성부는 같은 박에 겹칠 때만 반주음으로 씁니다. 반주음은 멜로디보다 낮게 유지합니다.
- 동시에 누르는 음은 줄이 겹치지 않아야 하고, 지판에서 **최대 손 벌림**(기본 4칸) 안에 들어가야 하며, 운지에 손가락이 4개를 넘으면 안 됩니다(바레 허용). 이 조건을 만족하는 운지 가운데 손 이동, 높은 포지션, 끊기는 지속음이 가장 적은 운지를 곡 전체에 걸쳐 고릅니다.
- 멜로디와 너무 멀거나 기타 음역 밖에 있는 반주음은 옥타브를 옮겨 멜로디 가까이에 두고, 그래도 손에 들어오지 않는 반주음은 생략합니다.
- **키 조정**을 자동으로 두면 원래 키에서 −5~+6반음 범위의 후보 키들을 비교해 기타로 가장 치기 쉬운 키를 고릅니다. 원래 키 유지도 선택할 수 있습니다.
- 악보에 코드 기호가 있으면 그대로(조옮김해서) 쓰고, 없으면 마디의 음(짝수 박자는 반 마디 단위)으로 코드를 인식합니다. 코드 운지표는 악보 위쪽에 모아 보여 줍니다. 멜로디만 있는 리드 시트는 코드 기호를 따라 베이스와 코드 구성음 반주를 만들어 붙입니다.
- **연습 설정 → 기타 타브 편곡**에서 키 조정·최대 손 벌림·반주 범위(멜로디+반주 / 멜로디+베이스 / 멜로디만)를 바꾸고, 선택한 키·옥타브 이동·생략한 음 수를 확인할 수 있습니다. **수정본 저장**을 누르면 편곡한 악보를 `.gp`로 저장합니다.

## PDF·이미지 악보

목록에서 PDF는 **PDF** 아이콘(이미지는 **IMG**)으로 표시됩니다. 파일을 누르면 먼저 원본 PDF·이미지가 앱 안에 열립니다. 상단 **타브악보로 변환**을 누르면 버튼 속 게이지와 함께 음표를 인식해 기타 타브로 표시합니다. 변환 후에는 재생 버튼 옆 **PDF ⇄ 타브** 버튼 하나로 원본과 편곡 결과를 전환할 수 있습니다. 원본 보기 중에는 악보 재생이 멈춥니다.

Guitar Pro·MuseScore 같은 악보 프로그램에서 PDF로 내보낸 **타브 악보**는 그림을 인식하지 않고 PDF 안의 글자와 선을 그대로 읽어 옮깁니다. TAB 줄의 프렛 번호와 위 오선보의 음표·쉼표·점·꼬리·빔·셋잇단음으로 리듬과 성부(여러 성부, 중간에 끝나는 성부 포함)를 맞추고, 카포·튜닝·템포(중간 변경 포함)·박자표·리허설 기호(A, B…), 하모닉스(N.H. / A.H. / T.H.), 붙임줄, 꾸밈음, 해머링·풀링(H/P), 슬라이드(sl.), 아르페지오·브러시, 피킹 방향, 데드 노트(X)를 원본대로 가져옵니다. TAB에서 숨겨진 붙임줄 끝음은 오선보 음표로 채웁니다. 이렇게 읽은 악보는 원본 그대로 보여 주므로 기타 타브 편곡은 꺼진 상태로 열립니다. 박자가 맞지 않거나 TAB 번호를 음표와 맞추지 못한 마디가 있으면 해당 마디 번호를 알려 줍니다. 스캔·사진 PDF나 TAB이 없는 PDF는 아래 Audiveris 인식으로 변환합니다.

변환에는 무료 악보 인식 프로그램 [Audiveris](https://github.com/Audiveris/audiveris/releases/tag/5.11.0)가 사용됩니다. 첫 변환 때 설치되어 있지 않으면 공식 설치 파일(Windows x64 MSI, macOS Apple Silicon/Intel DMG, 약 85MB)을 자동으로 받아 SHA-256을 확인하고 앱 설정 폴더에 풀어 둡니다. 시스템에 설치하지 않으므로 관리자 권한이나 별도 Java 설치는 필요하지 않습니다. 이미 설치한 Audiveris도 자동으로 찾습니다. 자동 설치가 실패하면 다운로드 페이지나 Audiveris 직접 지정(Windows `Audiveris.exe`, macOS `Audiveris.app`) 옵션이 표시됩니다. 인식은 한 페이지에 수십 초에서 몇 분이 걸릴 수 있고 결과는 파일 내용별로 저장해 재변환 시 재사용합니다. 목록에서 파일을 우클릭해 **타브 변환 삭제**를 누르면 저장된 결과를 지우고(열려 있으면 원본 보기로 돌아감) 다음 변환 때 처음부터 다시 인식합니다. 깨끗한 인쇄 악보일수록 정확하며, 손글씨나 흐린 사진은 음표를 잘못 읽을 수 있습니다.

지원 형식: GP3/GP4/GP5/GPX/GP/GP7/GP8, MusicXML, 악보 프로그램에서 내보낸 타브 PDF, 스캔 PDF·이미지(Audiveris 필요), 유튜브 링크.

## 유튜브 링크로 타브 만들기

홈 화면의 **유튜브 링크로 타브 만들기** 또는 왼쪽 **유튜브 ▶** 버튼에 영상 링크를 넣으면, 영상 소리를 받아 기타 음을 인식한 뒤 위의 기타 타브 편곡으로 보여 줍니다. 기타 소리만 나오는 영상일수록 정확합니다.

- 소리 받기: 처음 한 번 [yt-dlp](https://github.com/yt-dlp/yt-dlp)를 앱 설정 폴더에 내려받아 씁니다. 유튜브가 바뀌어 받기에 실패하면 yt-dlp를 한 번 업데이트하고 다시 시도합니다. 15분 이하 영상만 받고, 받은 소리는 영상별로 저장해 두었다가 다시 씁니다. 재생목록 링크도 해당 영상 하나만 받습니다.
- 음 인식: Spotify [Basic Pitch](https://github.com/spotify/basic-pitch-ts) 모델(`public\basic-pitch`, Apache-2.0)이 이 컴퓨터에서 동시에 울리는 여러 음을 찾습니다. 소리는 외부 서버로 보내지 않습니다. 기타 줄은 뜯은 뒤에도 울리기 때문에, 같은 음이 아직 울리는 중에 다시 잡히거나 함께 울리는 더 큰 음의 한 옥타브 아래·배음(옥타브, 12도, 2옥타브)으로 잡힌 음은 시작이 뚜렷할 때만 새 음으로 적습니다.
- 박자: 음이 시작되는 지점으로 템포를 추정하고 박을 따라가며(연주 중 빨라지거나 느려져도 따라감) 각 박을 가장 가까운 음의 시작에 맞춘 뒤 16분음표 단위로 맞춥니다. 핑거스타일의 고른 8분음표 흐름을 박으로 잘못 잡지 않도록, 베이스가 두 배 간격으로 더 뚜렷하게 반복되면 느린 쪽을 박으로 씁니다. 4/4박자로 적고, 베이스가 가장 자주 떨어지는 박을 마디 첫 박으로 잡습니다. 낮은 음은 베이스 성부, 나머지는 멜로디 성부로 나눕니다.
- 기타 배치: 영상과 같이 칠 수 있도록 녹음된 키와 옥타브를 그대로 두고, 쉬운 운지는 카포(0~7프렛)로 찾습니다. 표준 튜닝 맨 아래 E보다 낮은 음이 베이스처럼 자주(3% 이상) 나올 때만 Drop D·반음 내림·DADGAD·Open D·Open G·Open C 튜닝도 비교하고, 그때도 표준 튜닝보다 확실히 쉬울 때만 고릅니다. 기타로 닿지 않는 높이의 음만 한 옥타브 옮깁니다. 연습 설정의 키 조정은 녹음 변환에는 쓰지 않습니다.
- 코드 중심 운지: 곡의 코드 모양을 잡은 채 손가락 몇 개만 움직여 멜로디를 치는 핑거스타일처럼, 지금 코드의 운지표 위치(다른 튜닝은 개방현)에 있는 음을 우선합니다.
- 쉬운 음으로 바꾸기: 너무 어려운 곳은 멜로디 음을 한 옥타브 옮기거나 반주음을 가까운 코드 구성음으로 바꿉니다. 고른 튜닝·카포·키와 바꾼 음 수는 연습 설정의 편곡 요약에 나옵니다.
- 결과는 앱 설정 폴더의 `transcriptions`에 MusicXML로 저장되고 최근 목록에서 다시 열 수 있습니다. 자동 인식이라 틀린 음, 빠진 음, 어긋난 박자가 있을 수 있습니다.

## 소스에서 다시 만들기

Node.js 설치 후 이 폴더에서:

```sh
npm install
npm run package:win   # Windows
npm run package:mac   # macOS (Mac에서만, 기본은 현재 CPU. Intel용은 npm run package:mac -- x64)
```

완성된 파일은 Windows는 `release\fretroom.exe`, macOS는 `release/mac-arm64/fretroom.app`(Intel은 `release/mac/`)과 `release/fretroom-<버전>-mac-<arch>.dmg`·`.zip`입니다. 개발 중에는 `npm run desktop`으로 창을 띄우거나, `npm run dev`로 브라우저 버전을 사용할 수 있습니다. 최초 패키징에는 인터넷이 필요합니다. 악보 파일과 마이크 소리는 외부 서버에 업로드되지 않습니다. 음악 표기용 서체와 FluidR3 GM 음원은 EXE에 포함되어 있으며, 음원의 저작권·라이선스는 `public\soundfont\LICENSE-FluidR3.txt`에 있습니다. 화면용 Google Fonts 연결이 없으면 시스템 서체로 표시됩니다.

FluidR3 GM 음원(148MB)은 GitHub 파일 크기 제한 때문에 저장소에 들어 있지 않습니다. `npm install`이 이 저장소의 GitHub Release(`soundfont-v1`)에서 `public\soundfont\FluidR3_GM.sf2`로 받아 SHA-256을 확인합니다. 앱 아이콘 원본은 `build\icon.svg`이고, EXE와 창에는 `build\icon.ico`를 씁니다. macOS 앱 아이콘 `build/icon.icns`는 `npm run package:mac`이 `build/icon.png`로 만듭니다.

`npm install`은 `patch-package`로 고정된 alphaTab 1.8.4에 박자 간격, 데드 노트 재생(남는 채널의 뮤트 기타 음색으로 짧게), 스테레오 샘플 악기(FluidR3 드럼 등) 재생, 샘플이 없는 음이 이후 소리를 모두 끊던 문제, 같은 박에 붙은 표기(예: 구간 표시와 코드 이름)가 겹쳐 그려지는 문제, 여러 성부에 나뉜 화음(예: 베이스만 2성부)의 아르페지오·브러시가 성부마다 따로 굴러가던 문제의 수정 사항(`patches/`)을 적용합니다. 패키지 버전을 변경할 때는 해당 패치를 먼저 검토하세요.
